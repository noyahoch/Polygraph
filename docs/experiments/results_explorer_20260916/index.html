01 / CURRENT LAYER STUDY

Four layers versus the final layer

The comparison is four GNN detectors + a fitted logistic stack versus one final-layer GNN detector + a fitted logistic control. The four layer models are base detectors; the stack and final-only control are the two logistic meta-heads. This study does not add a new non-graph baseline. It tests the supplied layer-stack comparison, not a general claim that graphs are necessary.

    05 / TRACEABILITY & INTERPRETATION

    What this report can—and cannot—say

    The embedded JSON is the source of every displayed estimate. The page only formats values and scales charts; it does not recompute means, intervals, or method rankings.

    Evaluation units and uncertainty

    Photographs, photo–condition records, and fitted seeds are different units. Repeated seed predictions are not additional independent photographs. Current-study aggregate intervals are conditional on the supplied fitted seeds; sample SD across seeds is a separate descriptive quantity.
